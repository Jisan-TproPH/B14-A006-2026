This is a [Next.js](https://nextjs.org) project.
## Fitlog

this is a workout planning app created with next js . where you can find add plan workouts with cool ui.

### Technologies
    * Next.js
    * Tailwindcss
    * sonner
    * lucidia icons


### KeyFeatures 

    1. Responsive ui for [desktop and mobile] device 
    2. Planning system where you can track calories, minutes and excercises.
    3. Searching and sorting.
    4. DataStorage support (reload won't refresh your planning).
    5. Instant vissual feedbacks
